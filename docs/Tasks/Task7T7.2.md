## 查询契约

| 查询 | 数据和身份 |
| --- | --- |
| 数据集分页 | 复用 `SclBrowseIndex` 的数据集分类及 IED 范围行。按 XML 声明顺序返回数据集 NodeId、完整所属路径、描述和直接 FCDA 声明数。同名声明保持各自身份。 |
| FCDA 子页 | 复用父数据集的成员区间，按一基原始序号返回。重复声明保留独立 NodeId。返回原始 DO/DA/FC/ix、解析状态及解析得到的数组索引。引用记录连接同快照的候选、路径及失败理由。仅唯一解析时返回目标 NodeId。描述复用现有投影，只为交付页构建。 |
| 数据集使用方 | 使用解析器的反向索引，返回唯一解析至该数据集的报告、GSE、SV 控制块及其原始引用证据。可按控制块类型筛选。每个使用方保留自己的 XML 路径。 |
| 身份定位 | 按当前快照的 NodeId 在范围、父数据集和文本筛选之后定位所在页。未定位时交付空页，保留受限状态和观察计数，供界面区分未定位与结果受限。 |

范围使用实际 XML 所属 IED、AP 和 Server。数据集与成员分别按各自字段筛选。数据集和使用方可按完整路径或描述搜索，成员可按 FCDA 原始字段搜索。范围行数和文本命中数独立返回。子页另外区分有效空父项、父项在范围外和父项不可用。

单页最多 200 行。每次查询最多访问 100,000 条索引记录，使用方集合最多交付 512 条。触及上限且仍有未处理匹配的可能时，计数为已观察下界。`hasMore` 表示已经观察到可翻的后续行。列表顺序来自现有索引，内存仅保留本次待投影的页。

`SclHierarchyQuerySession` 通过 Qt Concurrent 执行，交付核验快照对象、范围和请求代次。列表、展开、使用方和定位可使用独立会话，每个会话保留一个工作任务和一个最新待处理请求。收起及隐藏取消对应请求，切换范围或文档重置会话上下文。应用层依赖 Qt Core/Concurrent，沿用现有快照和解析器。
