# Task6 · T6.4 工作台集成

2026-11-19。状态：**功能集成及回归通过**。本轮用户要求直接开展 T6.5，使用同一最终代码完成了此前未验证的 T6.4 布局与交互收口；综合指标和人工边界另见 [T6.5](Task6T6.5.md)。

## 交付

- `SclMmsView` 接入现有中央工作区，左侧任务导航与 XML 结构切换，保留 GOOSE/SV 和高级技术表。MMS 报告、实例、成员、未入数据集信号地址、客户端正反查、连接/能力、全工程 MMS 搜索和局部图均使用 T6.3 后台会话。
- `SclMmsPresentation` 在应用服务工作线程构建有界表格及字段投影。报告定义、原始 rptID、预期实例、Domain/Item 和数据集 MMS 列表名分开；字段保留缺失/空值/原值、解释与所在元素依据。GUI 不解析 XML、展开类型或扫描全目录。
- 详情复用现有 inspector Dock；字段表和列表复用 `SclTableInteraction` 的完整值复制、独立 Enter/按钮原文、可见行测高和超长值入口。普通字段完整换行，超长值的显示提示与复制值独立。
- 历史保留快照、范围、父报告、成员原始序号、记录/字段键、顶部记录及行内偏移。筛选遮挡清除行高亮并保留详情；同一数据集不替换父报告上下文。全局 MMS 搜索使用整个工程，打开结果时显式进入目标 IED。
- 基础与 MMS 问题共用文件检查入口和 JSON/CSV 导出。基础 0.2 和 mms-0.1 各自保留规则身份、覆盖及限制；CSV 文本继续防公式执行。完整 XSD、在线核实及工程点表完整性不显示为已执行。
- 局部图采用本地 Graphics View，箭头和边类型表达离线关系，候选/受限边用虚线并保留文字状态；可缩放、按节点列表使用键盘查阅。工程字段作为普通文本呈现，不上传页面或数据。

主/内部 ADS 继续独立管理。没有新增持久化 Dock，原三组内部 Dock 名称、版本 2 和布局摘要规则不变；新增的是同一中央区的路由和详情内容。销毁前断开指向工作台的子对象回调，避免 Dock 销毁后访问成员。查询替换、隐藏和关闭取消旧请求；关闭时释放查询上下文。
