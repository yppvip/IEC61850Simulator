# Task8 · T8.3 两级引用复制菜单

2026-11-21。T8.3 已通过。为任务视图和高级视图中的引用表格接入两级菜单。

## 用法

右键目标行，悬停在「对象引用」「MMS Item」或其他引用名称上，选择第二级中的值即可复制。也可选中行后按菜单键或 Shift+F10，用方向键展开，再按 Enter 复制。长值与多行内容在菜单中显示预览，剪贴板保留完整文本。

| 界面 | 引用来源 |
| --- | --- |
| MMS 结果和字段表 | 同一记录的地址、FC、数组组件、报告定义、预期实例、原始 `rptID`、数据集列表名，以及字段对应的原文证据。 |
| 本机信号、外部输入、GOOSE/SV 及检查任务 | 信号实例与类型、ExtRef 原始声明、已解析对象、数据集和控制块。声明的 `appID`、`smvID` 与端点数值 `APPID` 分开。 |
| 收发成员、发布成员、网络端点 | 发布 FCDA、接收 ExtRef、内部地址、端点和当前绑定或候选控制块。 |
| 高级数据集树、成员页、报告、对象、通信、模板和问题表 | 从右键命中的原始节点投影。模板可复制类型标识和类型引用。实例对象按已有工程或 MMS 映射证据提供。 |
| 高级搜索、引用及候选表 | 按原始命中、引用记录和候选身份投影。完整命中值来源于文件字段，候选路径单独标名。 |

复制引用只写入剪贴板。原有菜单中的单元格、整行、完整值、原文、拓扑及 MMS 查阅动作仍可使用。没有引用依据的行保留原菜单行为。

## 实现

共享菜单按命中行发起后台投影。投影携带完整值、类型和原文来源。FCDA、ExtRef 等原始声明从当前快照的源文本提取。分组最多交付 64 个值，受限时提示可在详情逐条查阅。

菜单打开期间核验文档快照、模型代次、命中索引和视图范围。模型重排、筛选、换文件或隐藏后，迟到结果无法补入旧菜单，旧动作也无法写入剪贴板。上下文菜单的引用复制不改动行选择、原文或统一历史。

在 `build/task8-t83` 完成 Windows Debug 构建和运行库部署，使用 Qt 6.11.1 / GCC 16.2.0。测试使用合成 SCD 和隔离的 QSettings。

- 原生 Windows Qt 程序驱动通过菜单悬停、Shift+F10、方向键和 Enter。逐字核对 MMS 属性、MMS 字段、高级 FCDA、GOOSE 发布行和发布成员的剪贴板文本。5,000 字符以上的 `rptID` 保留中文、首尾空格、换行、`&` 和 `$`。原桌面任务路径及原菜单动作通过回归。日志为 `build/task8-t83/T83Native.txt`。
- 筛选、重排及替换快照后尝试触发原动作，剪贴板保持原文本。人为推迟投影并变更筛选后，旧结果未进入已打开的菜单。
- 清洁 PATH 下 CTest 16/16 通过，耗时 45.43 秒。包括 `SclReferenceMenus`、引用来源投影、既有属性查阅、布局和 MMS 原型测试。日志为 `build/task8-t83/T83CTest.txt`。
