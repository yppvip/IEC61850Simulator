# T5.3 · 信号详情与结构浏览

2026-11-13。对应 [Task5](Task5.md) 的 T5.3。构建目录 `build/task5-t53`。

- 本机信号表分别显示对象名称、带来源的描述、对象引用、类别、CDC 和状态。描述来源标签只用于显示，完整值复制沿用 T5.2 的独立数据角色。
- 现有「属性与依据」Dock 提供「所选信号」页。标题显示完整信号引用，支持定位和复制引用。描述按来源呈现并提供原文链接，技术字段、通信使用与文件依据分区显示。进入信号表时隐藏中央说明和通用依据下拉框。
- 工作对象与原文对象分别保留。字段证据原文显示信号到证据的关系，独立选树显示结构浏览并保留返回所选信号入口。结构浏览不切换信号表的 IED 范围。过滤后按原始行身份恢复，遮挡时清除表格高亮并提供清除筛选后的重新定位。历史保存证据标签、选中信号及顶部原始行和行内偏移。
- 信号详情继续按快照和选择请求身份交付。切换时显示加载状态，失败后展示当前对象的错误状态。沿用内部 ADS 布局和既有停靠窗口。外部输入、GOOSE/SV 及关系详情保留各自页面。

## 验证

独立 Debug 构建与部署、CTest 9/9 通过。合成回归覆盖信号详情可见、筛选遮挡和重新定位、原文与返回、关闭和更换快照。Windows 原生清洁 PATH 使用同指纹真实样本复现滚出选中行、打开证据、选独立 DA、后退的流程。

原生 37,571 行单次测量：Ready 3,264 ms，详情 P95 63 ms，程序驱动滚动 P95 6.83 ms，峰值工作集 199,372,800 B。加载较 T5.0 的 1,947 ms 增约 68%，仍超过 15% 拟定目标。实体跨屏和 T5.2 的全表推广门槛继续单独验收。
