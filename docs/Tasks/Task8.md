# Task8 · MMS 信号查阅与表格引用复制

2026-11-21。[T8.0](Task8T8.0.md) 至 [T8.4](Task8T8.4.md) 已通过。属性查阅和两级引用复制已完成离线验收，包含真实工程样本走查和清洁 PATH 的 16 项 CTest。实际覆盖与查询限制见 T8.4 记录。

## 1. 需求确认

需求足以制定方案和开始实施。交付包括两项功能。

- 按 IED 查阅 SCD 中具有 MMS 地址依据的信号，能直接找到 A 相电压的幅值和相位候选，查看引用、功能约束、映射状态和原文证据。
- 任务视图和高级视图中，具有可复制引用的表格行提供右键二级菜单。第一层是「对象引用」「MMS Item」等引用名称，悬停或用键盘展开后可见对应值，选择第二层即可复制完整文本。

暂将“赋值相位”理解为“**幅值和相位**”。如果原意是“相位定值或设定值”，应按装置实际声明的定值对象、FC 和定值组查阅。实时测量量与文件中的定值分别展示。这个词义差异不阻塞公共查询和复制功能。

如需针对某台真实装置验收，可补充 IED 名称、相关 AP/LD 或回路描述、厂商点表中的信号名，以及目标量是保护输入、测量量还是设定值。有多套测量或保护回路时，应用保留各自证据并让用户选择。若目标包括在程序内直接读取设备当前值，需另行确认在线读取的范围。

## 2. SCD 能看出什么

**SCD 可以帮助判断文件模型中有哪些可映射到 MMS 的属性，以及怎样寻址。** 它记录工程配置。只要能从 IED 的 Server 和 LN 实例沿类型模板唯一解析到属性，且功能约束、命名和 MMS 映射有依据，就可以给出离线地址。设备当前在线模型、客户端权限、实际值和读取是否成功，需要通过针对实际设备的在线验证确认。SCD 中的实例 `Val` 是文件值，界面应标明其来源。 [IEC 61850-6](https://webstore.iec.ch/en/publication/103863) · [IEC 61850-8-1](https://webstore.iec.ch/en/publication/66585) · [libiec61850 客户端读取](https://support.mz-automation.de/doc/libiec61850/c/latest/group__IEC61850__CLIENT__DATA__ACCESS.html) · [服务端访问控制](https://support.mz-automation.de/doc/libiec61850/c/latest/group__IEC61850__SERVER__EXTERNAL__ACCESS.html)

| 查阅目标 | 文件依据与显示口径 |
| --- | --- |
| 直接读取候选 | 从实例、数据对象、属性和有效 FC 推导对象引用及 Domain/Item。报告数据集成员资格独立展示，未加入数据集的属性也能查地址。 |
| 通过报告间接获得 | 从唯一解析的 ReportControl → DataSet → FCDA 查看已配置成员，保留声明层关系和匹配依据。按 DO 级成员查属性时核对 FC、层级与数组范围。实际可用的报告实例、启用状态及报告内容由在线结果确认。 |
| GOOSE/SV 中有哪些量 | 显示其各自的数据集及成员证据。同一信号可以被多种服务使用，MMS 直接映射和报告使用分别判断。 |
| 实时幅值、相位、品质与时间 | 离线显示可解析的属性路径及已声明的类型、单位或品质/时间属性。当前数值和在线访问结果由设备提供。 |

### A 相电压示例

对某个 IED，先找实际的测量 LN 和电压对象。如果实例模型确实包含该结构，`PhV.phsA.cVal.mag.f` 可以对应 A 相对地电压幅值，`PhV.phsA.cVal.ang.f` 可以对应相位。以下路径使用合成名称，具体工程可能有不同 LN 前缀、实例号、属性形式或厂商扩展。角度是否存在、选用哪个叶属性、单位和角度参考均以该装置模型或厂商证据为准。一个测量 LN 提供 A 相电压，也不足以确认它就是某个保护功能内部使用的输入。 [IEC 61850-7-3](https://webstore.iec.ch/en/publication/6016) · [IEC 61850-7-4](https://webstore.iec.ch/en/publication/66551) · [ABB RIO600 的 IEC 61850 电压字段命名示例](https://techdoc.relays.protection-control.abb/r/RIO600-Installation-and-Commissioning-Manual/1.8/en-US/LD0.VMMXU-voltage-measurements)

| 字段 | 合成示例 |
| --- | --- |
| 电压幅值属性引用 | `DemoIEDLD0/MMXU1.PhV.phsA.cVal.mag.f` |
| 电压相位属性引用 | `DemoIEDLD0/MMXU1.PhV.phsA.cVal.ang.f` |
| 功能约束 | `MX`，取自实际 DA，嵌套 BDA 继承它 |
| MMS Domain | `DemoIEDLD0`，按已有规则使用有效的显式 LD 名或可推导名 |
| 相位的 MMS Item | `MMXU1$MX$PhV$phsA$cVal$ang$f` |

### 当前程序的入口与缺口

「任务视图 → MMS 查阅 → 信号地址」可在选定 IED 后搜索对象，再打开「查看属性与地址」。即便文件没有 FCDA 引用该对象，Task6 的对象目录仍可展开它。 [Task6 T6.4](Task6T6.4.md)

T8.2 在同一入口增加「查找属性」。可输入 `A 相电压` 直接查找幅值与相位候选，分别核对离线地址、报告覆盖和原文。在高级表也可从对象或 FCDA 进入同一查阅页。T8.3 在两种视图中提供两级引用复制。 [T8.2 阶段记录](Task8T8.2.md) · [T8.3 阶段记录](Task8T8.3.md)

## 3. 实现方案

### 3.1 按装置查 MMS 信号

复用现有「MMS 查阅 → 信号地址」及其详情区。任务视图在该入口提供按当前 IED 查找属性的路径，高级表上的对象、FCDA 或对应引用可跳到同一查阅位置。使用同快照、IED/AP/Server、LN 实例、对象路径、属性路径、FC 和数组访问身份定位。沿用 Task7 的统一历史和详情 Dock。

支持从描述、完整路径、MMS Item 和能够以模型结构证明的业务词查找，例如「A 相电压」「幅值」「相位」。候选应显示 IED/AP/Server/LD/LN、完整路径、来源描述及匹配理由。词语匹配用于查找候选。若文件只说明它是一个电压测量量，详情继续显示测量语义和出处，由用户结合回路或厂商点表确定其保护用途。

每条属性或成员分别展示以下证据。

- **直接映射**显示离线地址已推导、结构访问、数组待选、歧义、缺少定义或查询受限。所有行的在线确认状态独立显示为「未验证」。带下标的成员保存原始 `ix`、有效索引及已有 alternate access 组件。数组未选元素时保持结构与限制。
- **报告使用**列出已解析的数据集和报告定义及匹配类型。完整属性匹配与 DO 级成员的结构覆盖明确分列。结构覆盖须有相同对象实例、FC、嵌套路径及数组边界的证据。重复 FCDA 保留原始出现次序，方向和报告来源仍由 Task7 历史恢复。
- **原文依据**链接 LN、DO/SDO、DA/BDA 定义和 FC 来源。品质、时间、单位、角度参考及文件定值等字段有实际声明时可单独核对。空状态区分文件未提供证据、未找到匹配、查询受限和当前范围外。

在应用服务后台复用 `SclSnapshot`、`SclTaskIndex` 的对象与范围索引、`SclReferenceResolver`、`SclMmsQuery`、`SclMmsPresentation` 和描述解析。先复用属性按需展开与报告反查，结合阶段证据决定是否需要轻量索引。列表、定位、详情和复制所需查询使用独立请求代次。沿用任务后台分页和工作预算，切 IED/AP/Server、换文档或隐藏时取消旧请求。Task8 实施范围是离线只读查阅和复制。

### 3.2 引用复制菜单

按**右键命中的记录**生成菜单。第一层直接显示引用字段名称。第二层显示该字段已有的完整值或可识别的预览，多值逐条可选。实际写入剪贴板的是所选值的原始完整文本。键盘通过菜单键或 Shift+F10 打开，方向键展开，Enter 复制。

```text
对象引用       → DemoIEDLD0/MMXU1.PhV.phsA.cVal.ang.f
功能约束       → MX
MMS Domain     → DemoIEDLD0
MMS Item       → MMXU1$MX$PhV$phsA$cVal$ang$f
原始 FCDA 声明 → 文件中对应声明
```

| 表格来源 | 有证据时提供的引用类字段 |
| --- | --- |
| 信号、属性地址、对象和原文依据表 | 对象/属性引用，FC，MMS Domain、Item，数组访问组件及能识别的类型引用。 |
| 数据集、FCDA、报告及相关查阅表 | 数据集引用、原始成员声明、派生对象引用、报告定义引用、预期实例引用、原始 `rptID` 和 MMS 数据集列表名，分别命名。 |
| GOOSE/SV、收发关系、连接配置 | 数据集、控制块、ExtRef 声明及对象引用。原始 `appID`、`smvID` 与数值 APPID 如有可复制字段分别标记。 |
| 搜索结果、问题、模板、关系及候选表 | 从该命中或记录的原始身份取得相关引用。候选明确标名。缺少引用的普通行、占位和加载行保持原菜单。 |

覆盖任务视图、高级视图及其相关详情和搜索表格。T8.0 先列出全部表格与提供方，逐类记录适用字段及空态。类型定义行只有模板身份时提供类型引用，实例引用需要同快照中的具体实例。候选项保留候选语义。受限的多值集合通过分页详情逐条复制，菜单提示当前可见范围。

应用服务或模型交付类型化条目，包含名称、完整值、来源和记录身份。优先复用既有全值角色及 MMS 完整字段投影，在 `SclTableInteraction` 抽取共享菜单构建，也接入高级表当前的拓扑菜单、数据集树表和收发关系表。已有「复制单元格／行」「查看完整值」「查看原文」「打开引用拓扑」保留各自操作。复制引用本身只写剪贴板，可提示复制结果。

点击第二级前核验同一快照、视图结果代次及原始行或字段身份。筛选、重排、换范围或换文件后，旧菜单项不能复制到另一对象。复制内容直接来自原值或已验证的派生字段，无需解析列标题、显示文本、富文本路径或省略号。长值、中文、空格、多行、`$` 等字符保留。按需取得完整值时沿用后台交付，界面只呈现有界条目。

## 4. 执行顺序与门槛

按阶段验证后再继续。实现记录写入各阶段文档，工程样本仅在本地只读验收，常规自动化采用合成样本。

| 阶段 | 工作 | 验收门槛 |
| --- | --- | --- |
| [T8.0 现状基线与术语](Task8T8.0.md) | 在清洁 PATH Debug 复现现有 MMS 属性路径，冻结表格和菜单矩阵，建立 A 相电压正反例。 | 已记录当前能查到的项目。合成模型覆盖完整幅值与相位、缺相位、未入数据集、同名跨装置和保护量语义不明确。明确当前值、定值与文件原值的区别。 |
| [T8.1 查询与引用值投影](Task8T8.1.md) | 在现有后台会话上扩展属性检索和类型化引用项。统一直接地址状态与报告证据。 | 验证显式与推导 LD、嵌套 DA/BDA、FC、重复成员、DO 级覆盖、数组、未知类型和歧义。未入报告仍可映射。有界分页、取消和快照切换通过。 |
| [T8.2 信号入口与证据](Task8T8.2.md) | 接入按 IED 查找 MMS 属性、幅值/相位定位、表格到查阅位置、已解析报告使用及原文。 | 在选定 IED 正确定位 A 相的两个叶属性，多候选按范围区分。返回恢复原选择和作用域。缺证据、受限和未在线验证均可辨识。详情收起、窄窗及旧布局回归。 |
| [T8.3 两级复制菜单](Task8T8.3.md) | 先在 MMS 属性表和高级 FCDA 树表试点，再覆盖 T8.0 矩阵中其余有引用的表格。 | 悬停及键盘访问可用。每个类型复制内容逐字对比，保留长值和特殊字符。点击菜单不进入原文或改变业务历史。重排、换文件及迟到结果不能复制错行。原菜单动作回归。 |
| [T8.4 集成验收](Task8T8.4.md) | Debug 构建、部署和清洁 PATH CTest。以脱敏夹具及用户指定样本做本地走查，记录实际覆盖和限制，同步项目说明。 | 任务及高级视图均可查阅并复制同一已解析引用。真实样本中的字段按当前装置模型验证。样本缺少的场景用合成夹具补足，在线读取状态继续单列。 |

验收示例从选定 IED 开始，搜索「A 相电压」，分别打开幅值和相位，核对类型模板、FC、Domain/Item 与原文。再从高级数据集成员进入同一属性，核对报告使用与返回路径。最后分别在两种视图使用右键「对象引用」与「MMS Item」，将剪贴板与同快照的完整字段逐字比较。
