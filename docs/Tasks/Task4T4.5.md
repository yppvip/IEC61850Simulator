2026-11-12。候选程序位于 `build/task4-t45/bin/IEC61850Simulator.exe`。MSYS2 UCRT64、GCC 16.2.0、Qt 6.11.1、Ninja、Debug。运行时 DLL 与 Qt 插件已部署在同级目录。主程序 SHA-256 为 `54B364AA42719BAA985A0330B71DE4012FDC9FCA6115B5B596685672EC2ABFDF`。

任务页使用 Qt 原生控件、图标和键盘行为。信号页区分本机对象与外部输入。GOOSE 和 SV 分别提供发送配置与有服务类型证据的接收声明。服务未知的接收声明仍可在外部输入中查看。任务详情随选中条目展示，点文件依据时展开原文 Dock。高级视图保留原布局操作与拓扑。

## 本地验证

- Debug 构建、运行时部署与常规 CTest 9/9 通过。测试包含干净 PATH 启动、有/无 Redis、布局恢复、快照生命周期和任务页导航。合成 512,000 条路径的样本验证目录在 500,000 条处停止并报告覆盖受限。
- Windows 原生窗口以干净 PATH 使用自建样本走查 100%、150%、200% 缩放。200% 同时使用 Fusion 高对比测试调色板。原文、历史和高级视图均可操作。截图保存在构建目录。
- 真实 SCD 得到 190,666 条对象路径、7,138 条共享定义、205 条 GOOSE 发送配置、32 条 SV 发送配置和 3,194 条外部输入声明。目录与关联上限均未触发。100 次信号详情请求的 P50/P95/P99/最大值为 62/63/64/69 ms，包含测试轮询及 Qt 事件派发时间。
- 十轮加载关闭均通过，每轮确认旧快照释放。首次加载 10,407 ms，热态中位数 10,328 ms，较 T4.0 低约 0.6%。峰值工作集 451,047,424 字节，较 T4.0 增加约 1.2%。关闭后私有字节在 65.6–72.6 MB 间波动，末轮为 69.6 MB。样本 SHA-256 前后一致。
- 真实 SCD 在相同原生环境中复跑扩展交互测试。下表为每类 100 次热态操作，耗时截止到 Qt 事件派发返回。Windows 桌面合成时间未单独计入。

| 操作 | P95 ms | P99 ms |
| --- | ---: | ---: |
| 树选择 | 18.72 | 19.25 |
| 树选择，详情收起 | 21.47 | 22.32 |

原生交互心跳最大间隔为 171 ms。全工程搜索每次交付最多 4,096 行，后台等待队列最多 16,384 行。取消会唤醒等待队列空间的任务，最后一批已交付时才发布完成事件。一次早期测量记录了 72.03 ms 的单批异常值，当时批次日志写入计时区间。将日志移出计时区间后复跑，174 批中交付最大耗时 0.50 ms。
