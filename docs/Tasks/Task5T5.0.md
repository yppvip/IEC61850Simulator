## 1. 表格交互盘点

| 表格 | 当前选择与激活 | 当前复制入口 | 后续保留的定位入口 |
| --- | --- | --- | --- |
| 任务视图共用表（信号、本机发布及外部输入的 GOOSE/SV、文件检查） | 当前项变化异步加载详情；`activated` 打开依据下拉框当前证据，依据未就绪时无动作 | 详情可选文本；无单元格复制动作 | 现有原文按钮与 Enter，明确所用证据；文件检查保留问题原始序号 |
| 高级报告、数据集、成员、对象、通信、模板 | 当前项变化通过 NodeId 同步树和检查器；无表格 `activated` 连接 | 无单元格复制动作；部分有独立引用拓扑入口 | 保留选择同步，原文由明确的入口打开 |
| 高级问题 | 当前项以原始问题序号选择；`activated` 再打开原文 | CSV 导出；无单元格复制动作 | 原文动作及 Enter，按原始问题序号定位 |
| 高级引用与使用方、候选 | 选中引用更新路径与候选；两张表分别通过 `activated` 跳转。引用表仅跳转有明确目标的行，候选表可跳转用户选定的候选 | 独立“复制声明”和“复制推导引用”按钮 | 明确目标用“定位”与 Enter，歧义先展示候选 |
| 高级搜索结果 | `activated` 按命中的节点或问题原始序号跳转 | 无单元格复制动作 | “定位”与 Enter，保留命中类型与历史 |
| 收发关系成员映射 | 当前项变化更新成员详情与图；无表格 `activated` 连接 | Ctrl+C 把所选项显示文本用制表符连接（当前按整行选择） | 现有源成员/接收输入原文按钮和路径链接 |

GOOSE/SV 任务详情中的成员目前是文本（最多 24 项）。独立成员表只存在于收发关系页（每页最多 200 行）。属性与依据中的属性正文为富文本。关系树和 Graphics View 双击仍按 T4.6 约定处理。

后续表格单击选择工作行并记住字段，双击、Ctrl+C 与右键“复制单元格”取同一完整字段，Ctrl+Shift+C 与右键“复制行”按可见列顺序取值。Enter 调用明确的原文或定位动作。迁移时将鼠标激活与键盘动作分流，并验证一次物理双击只触发一次复制、原文按钮和 Enter 均可完成原跳转。直接把双击交给编辑器会占用现有跳转手势。当前表格为只读，任务页和映射页禁用编辑触发，高级表与搜索模型未提供可编辑字段。

选择键包含快照身份、表类别、IED/数据集范围、方向及原始实体身份。信号保留 LN 实例（含 AP/Server）、模板路径、FC 与数组访问；高级节点用 NodeId，问题用原始序号，搜索保留命中类型；发布流用控制块节点，成员用数据集节点加原始序号，收发映射再保留接收 IED 与 ExtRef。字段用列对应的稳定字段标识。可见行号只用于显示，过滤和分页后重新映射。异步回填须校验快照、工作对象、范围和请求代次。原文证据单独保留来源 NodeId；共享模板不反向选取任意实例。复制取原字段或已标明的完整派生值，保留原始换行、大小写和前导零，空字段不覆盖剪贴板。当前任务单元格投影存在 512/2048 字符截取，不能直接复用其显示字符串。

## 2. 描述来源与后续用例

原路径不可访问，改用本机 D:/3Document 下同名样本，SHA-256 与 T4.6 一致：`1E46B6FC5255407E0663D63D7F9CCB8BC07CCFA457906157BF125C7C6B0FD7FE`。使用禁 DTD、禁外部解析的 XML 读取核对声明。PL2201B 的 PI1 / Break1PTRC1 中，Tr 有一处实例 desc、一处 dU Val、一处模板 DO desc；phsA 的模板 DA 声明无 desc，实例 DAI **有 desc**。两类属性来源需要分别查找。这里只验证声明存在性。当前信号表从首条成员使用取 dU，再回退到模板 DO 描述，实例 desc 和未入数据集的 dU 因此需要 T5.1 的共享解析。

| 合成用例 | T5.1 预期 |
| --- | --- |
| 唯一实例同时声明 dU、对象 desc、属性 desc，模板 DO/DA 有不同文本 | 分别记录原值和来源，默认对象标题可用唯一且语义已确认的 dU |
| 无 FCDA，两个 LN 或 AP 复用同模板 | 仍分别读取各自实例描述；缺失时才使用对应模板 DO 描述 |

| 多个 Val、sGroup、多数组实例或目标有歧义 | 保留候选及受限原因，禁止取第一项 |
| 同一个目标在数据集重复出现 | 目标描述可共享，成员证据保留各自原始序号 |

`Task4Signals.scd` 已有共享模板、跨 AP、未入数据集、模板 DO 有描述且 DA 无描述的基础样例。实例来源、数组和定值组用例在 T5.1 写入合成夹具并执行断言。
