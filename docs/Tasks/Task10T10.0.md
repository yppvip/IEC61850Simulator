## 4. 实际来源与展示矩阵

| 入口 / 字段 | 当前提供方及身份 | 当前取得方式 / 原文行为 | Task10 缺口 |
| --- | --- | --- | --- |
| 信号对象列表 | `SclSignalCatalog` → `SclMmsQuery::Signal`；LN + signal 记录 | 目录按实例绑定类型展开；任务“信号对象”已有 CDC 列 | 不应重复宣称全部页面均无 CDC；缺少对象来源与数据集资格摘要 |
| 属性与地址 / 查找属性 | `Query::Addresses/Attributes`；LN、signal、field、FC、声明/模板路径、数组身份 | 按唯一类型链展开；Domain 命名和 Item 映射分别保留；不要求一定有 FCDA | 属性页未直接显示当前对象 CDC、DO/DA 分界、数据集证据；默认说明不足 |
| MMS Domain | `domainsByDevice` + `domainEvidence` | 显式 ldName 或 IED 名与 LD inst 推导；字段来源可跳所在元素 | 表格默认只写“离线 LD 命名依据”，缺少所有组成输入和可见行号 |
| 属性 MMS Item | `templatePath`、有效 FC、LN 名 → `SclMmsPresentation` | 本轮默认说明为“离线属性映射”；字段原文实际跳 BDA `f` | 多输入组成、规则和数据集关系未直接解释；看上去像是从某行直接摘取 |
| 报告/数据集成员 | `ReferenceAnalysis` + `fcdaTraces` → `Members` | 原 FCDA 的 doName、daName、fc 保留；无 daName 的成员显示“DO 对象成员”；字段原文可到 FCDA | 默认通用八列表头含义混合；未声明 daName 常只表现为空缺；无 CDC 及完整边界解释 |
| 属性报告使用 | `membersByLogicalNode` + `MatchReport` + `reportsByDataSet` | 后台已区分精确属性、上级属性及 DO 覆盖；保留重复成员和父报告 | 仅有报告使用方；不能替代全体数据集关系或“未引用”的完备判断 |
| 三类原文 | `SclMmsView::OpenSource/OpenRowSource`、工作台源预览 | 属性字段到模板 BDA；成员字段到 FCDA；高级选择 DataSet 可到 DataSet 标签 | 没有统一并列的“数据集声明 / 实例配置 / 类型定义”入口；没有可解释的实例祖先回退 |
| MMS 字段与依据表 | `DescribeSclMms` → `ApplyDetail` | 默认三列“字段 / 完整值 / 解释/来源”，有节点依据但默认不显示行号 | 须补多来源、取得方式、精度；规则没有 XML 行号，应区分规则说明与原文输入 |
| 引用组成图 / 证据树 | `SclReferenceValues/Trace` → `SclReferenceTraceView` | 已有分支展开和可信标签起始行，可显式打开原文 | 应将必要解释前置到列表/详情，复用证据而非要求新手先逐层展开图 |
| 高级对象 / FCDA 树表 | `SclWorkspace`、`SclDataSetView` | 对象列为对象、位置、描述、lnType/type、bType、FC、count/ix；树表按成员身份交付 | 当前默认列无 CDC；树表“类别/FC”不能代替明确的 DO/DA 边界 |
| 高级模板 | 模板分类及类型引用 | 现有“LN 类 / CDC”列 | 保留；不能将未绑定 LN 的模板直接称为实例信号 |

原文实测：SCD 叶 Item 跳第 221940 行，成员 doName 跳第 2789 行；ICD 叶 Item 跳第 7609 行，成员 doName 跳第 1435 行；高级 DataSet 定位分别到第 2788 / 1430 行。因此当前“查看原文”并非统一指向实例 DAI，不能笼统承诺它已覆盖用户要求的两类位置。

## 5. 冻结范围、状态及语法决策

以下为 T10.1 及后续实现的验收输入，不表示本阶段新增了这些功能。

| 入口 | 默认范围与上下文 | 空态 / 不确定状态 |
| --- | --- | --- |
| 信号地址 / 属性 | 当前 IED 与已有 AP/Server 语境；直接目录保留全部可解析模型属性 | “当前范围未发现数据集引用”须检查全部适用数据集，且没有影响结论的未解析候选；否则尚未确定 |
| 从报告成员进入 | 保留原报告、DataSet、FCDA 原始序号和解析语境 | 首先解释当前数据集的精确/结构/对象覆盖；切全体关系是显式查询 |
| 属性报告使用 | 沿用当前属性的完整访问身份 | 现有“未找到已解析报告使用”文案成立；不得改写为“没有数据集” |
| 全工程搜索 | 整个工程，不随 IED 选择暗中收窄 | 预算耗尽是结果不完整，不是目标不存在；不作为校核的唯一实现 |
| 数据集关系 | 按信号身份/FC/数组查询，保留成员源范围与目标范围 | 精确、属性覆盖、对象覆盖可同时存在；未使用数据集仍列出；计数保留观察下界 |
| 三类原文 | 数据集声明、实例配置、类型定义各守其链 | 缺实例叶时只能回退到真实已匹配祖先，并说明缺失段；候选不唯一不选首项 |

校核输入首期冻结为普通信号对象引用与 MMS Domain+Item：对象引用用 `LDName/LNName.DO[.SDO…][.DA.BDA…]`，FC 独立输入或由唯一有效属性依据给出；Item 用 `LNName$FC$DO[$SDO…][$DA$BDA…]`，Domain 与 IED/AP/Server 上下文不能混同。当前正向映射会检查名称组成和唯一类型链，**当前没有可供用户粘贴校核的独立解析入口**。

数组仅接入现有解析器能够明确表达的选择及 alternate access；未选、多轴或未支持形式列限制。对象/结构地址通过不等于叶标量通过。RCB、MMS 数据集列表名、rptID 及其他控制引用不进入普通 Item 判定，识别后提示类别或未支持。格式、模型、映射、数据集及在线状态分层；未知版本、不支持语法、预算限制和上下文不足不得判非法。唯一目标才可提供成功任务页导航。

## 7. 同机性能口径与结果

正式采集为每个样本 10 个全新 Windows Qt 测试进程，按 SCD→ICD 交替，1280×800、默认 DPR；不同时运行其他本任务测试。每次新建隔离 QSettings、读取文件、按同一目标对象和字段顺序执行定向查询、页面/详情、原文与返回，最后验证源指纹和快照释放。OS 文件缓存不主动清除，所以这里是常规缓存状态下的同机基线，不能称为磁盘冷启动。

截图采集为独立试跑，不计入正式内存/性能样本。早期探针试跑包含图片或与回归重叠的采集，保留于 `pilot-local/`，不纳入正式统计。最初可见性断言失败日志 `IcdFirst.log` 保留；最终探针将可见性作为独立观察值保存，不将失败样本丢弃。

| 指标 | 边界 |
| --- | --- |
| Ready ms | `SclAnalysisService::Open` 至 GUI 观察到完整 Ready；QTRY 观察粒度影响短文件结果，不是纯 XML 解析时间 |
| 峰值工作集 | 每个全新进程完成本轮所有检查后的 Windows PeakWorkingSetSize；包含 UI 与测试探针，不只包含 SCL 模型 |
