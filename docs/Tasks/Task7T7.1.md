# Task7 · T7.1 MMS 导航闭环

日期：2026-11-20。状态：**功能修改完成，功能回归通过；性能对照未通过 +15% 门槛，未标整体通过。** 只执行 [Task7](Task7.md) 的 T7.1；T7.2–T7.5 未实施。用户要求不再追加过多测试，本轮在已有最终证据上收尾。

## 1. 用户可见行为

MMS 查阅区增加“后退 / 前进”和带目标名称的“上一级”。后退、前进及 Alt+Left/Right 使用工作台已有的一组历史命令；上一级按当前业务路线返回。分页独立显示为“上一页数据 / 下一页数据”，选择行、筛选及分页只更新当前位置。

- 从报告进入成员、信号对象、属性地址后，上一级逐层恢复原父页；两个报告共用数据集时，各自保留来源报告及成员选择。
- 路径可点击祖先，也可在“完整查阅路径”菜单跳转或复制全文。报告和数据集保留完整所属路径，用来区分同名对象。工程字段编码后显示，链接只使用当前路径代次和祖先序号。菜单最多展示最近 12 级，超过时明确提示较早路径可逐级返回，并将复制动作标为“复制已展示的查阅路径”。
- 原“继续查阅”改为“查看数据集成员”“查看信号对象”“查看属性与地址”等。引用未解析时使用“查看候选与依据”，打开现有详情，不自动选择候选。
- 全工程搜索具有单独的“返回搜索结果”入口；上一级仍沿业务父链。客户端反查跨 IED 后，上一级恢复原客户端列表和范围。
- 高级表直接进入报告按快照中的准确身份定位，不按名称筛选。直接进入 FCDA 时，上一级是其实际所属数据集；直接进入属性地址时，上一级是信号对象。没有明确来源报告时不选用任意报告。
- 短窗将路径折叠到“查阅路径”菜单，保留上一级；窄窗的后退/前进使用标准图标，提供可访问名称与提示。窄窗全工程搜索通过“搜索”按钮打开输入框，查询仍在后台执行。

现有 ADS Dock 结构和持久化版本 2 保持有效。短窗只在默认上下两区排列时按可读行所需空间调整分隔位置；自定义、标签化及浮动布局沿用用户排列。详情收起后继续查阅及返回不会强制展开。

## 2. 实现与状态约束

| 位置 | 本阶段实现 |
| --- | --- |
| `src/gui/SclMmsView.*`、`SclMmsNavigation.cpp` | Location 保存同快照父链、搜索来源、IED、列表及字段身份、筛选/页码、顶部记录/行内偏移、横向位置和详情显隐。父链是统一历史的位置元数据，不是第二个后退栈。 |
| `src/gui/SclWorkspace.*` | 页内历史复用统一命令；任务/高级切换作为单次历史操作。异步恢复完成后更新当前位置；已恢复的同一 XML 节点避免重复刷新范围。 |
| `src/core/SclMmsQuery.*` | 后台 `locate` 在范围及筛选之后按完整记录键定位所在页，最多交付 200 行，沿用 100,000 工作单元预算。未找到时清空行并说明可能被遮挡或受限。新增直接 DataSet 成员查询只接受同快照的标准 DataSet 和有效作用域。 |
| `src/core/SclMmsPresentation.cpp` | 为定位页补齐成员描述；成员详情增加已有解析状态、原因及最多 64 个目标/候选证据，保留原解析状态及字段预算。 |

恢复时取消旧列表和详情请求。应用服务继续校验快照对象、范围与独立请求代次；GUI 的延迟锚点恢复另校验视图代次和可见性。切范围、隐藏或关闭会取消回调；文档切换清理父链、搜索来源、路径菜单及历史，旧快照可以释放。

范围内被筛选遮挡的选择保留其身份和详情，清除旧行高亮，不默认选第一行。新结果到达前，上一页暂时禁用；完整页只重置模型一次。列表稳定、字段与滚动恢复完成后才发布恢复位置。宽窗路径区域保持稳定高度，避免长短标题反复调整两个面板。

复制继续使用完整值，双击复制与 Enter/原文按钮分离；路径菜单额外提供完整路径复制。没有增加解析器、在线地址探测、协议连接、报告订阅、第三方图标或独立工具。直接数据集查询只是本阶段规范父级所需的入口，**不代表 T7.2 的高级数据集树表已实现**。

## 4. 发现与修正

初版窄窗探针只检查控件自身区域，曾出现测试通过而截图中的原文被上层 ADS 区域裁剪。修正探针后测试确实失败；随后调整短窗路径、内容最小尺寸、源预览伸缩及上下区分配，并预留延迟出现的水平滚动条和底部边距。此前失败日志/截图保留在忽略的构建目录，不能将早期弱断言通过当作最终证据。

一次将 CTest 与原生矩阵同时运行时，narrow-200 的 Alt+Left 未触发；独立重跑五档曾通过，后又复现，不能据此确定外部干扰原因。探针原本未确认活动窗口与键盘焦点，现已在发键前确认窗口活动及表格取得焦点；最终五档通过，不绕过实际快捷键处理。原生键盘和性能测试独立运行。一次配对复测在第三对新版加载时，会话提前返回 Empty，缺少有效数据；该组未计为完整三对通过。脚本新增 running/failed/complete 状态，避免中断后遗留旧 Comparison 被误读为当前结果。相关失败日志均保留。

检查直接 DataSet 入口时发现，成员声明可存在而有预算的成员引用索引未覆盖，原列表投影会读取缺失记录。补充有界回退及单测：显示声明原文、Blocked 状态和限制，不推导目标/地址。短窗适配增加分隔器方向及顺序检查，水平自定义布局的尺寸保持由原生测试复核。

首次三对性能复测中，加载和峰值内存通过，但部分路径 P95 超过 +15%；最多为 signalBack +78.23%。消除恢复前的重复模型清空、重复路径菜单生成后，第二组三对仍有超限，最多为 signalToAddresses +51.44%。继续消除同节点重复范围刷新，并固定宽窗路径区域高度，再复测。历次证据分别保留，未放宽阈值或删除失败结果。
