# Task8 · T8.1 查询与引用值投影

2026-11-21。T8.1 已通过。实现了离线属性检索、属性级报告反查及类型化引用。界面入口按 [Task8](Task8.md) 将在 T8.2 接入，两级复制菜单在 T8.3 接入。

## 查询和证据

| 查询 | 交付 |
| --- | --- |
| `Attributes` | 在 IED、AP、Server 范围内查询属性，可按 FC、完整路径、MMS Item、描述或业务词筛选。`A 相电压` 由 `PhV.phsA`、CMV、`MX` 和实际幅值或相位路径提供结构依据。`相位` 同时可能匹配描述中带有该词的定值，按 FC 和匹配理由区分。 |
| `Addresses` | 与属性检索共用展开逻辑。保留 LN、对象和 DA/BDA 定义，以及 FC 所属 DA、显式或推导 Domain 的原文依据。区分已映射、结构、数组待选、alternate access、歧义、定义缺失和映射受阻。在线状态单列为未验证。 |
| `AttributeReports` | 以属性键查询唯一解析的 ReportControl → DataSet → FCDA。核对 LN 实例、FC、模板路径和数组维度，区分精确属性、上级属性覆盖和 DO 级覆盖。每个 FCDA 保留原始序号，使用同一数据集的报告保留各自身份。没有匹配报告的属性仍可有直接地址。 |
| `Detail` | 按完整记录键定位字段。地址的完整值和原文依据通过相同属性投影返回。选中成员可取原 FCDA 开始标签，保留原文换行、引号和实体写法。报告定义、预期实例、原始 `rptID`、数据集引用和 MMS 列表名分别投影。 |

属性键保存 LN、目录记录、属性路径、FC、声明节点和数组选择。未选择数组元素时不给出 Item。已解析 FCDA 可以提供数组选择依据，同一模板复用的其他对象路径保持各自的数组身份。选定元素的基础 Item、有效下标、alternate access 组件与原始 `ix` 分别交付。查询结果同时带快照文档、原文索引及请求代次，沿用 `SclMmsQuerySession` 的分页、取消和交付校验。单页最多 200 行，每次最多 100,000 工作单元，触及预算时总数是观察下界。

类型化引用投影交付完整值、来源节点及显式或派生状态。列表按交付页生成；原 FCDA 标签按所选记录从同一 `SourceIndex` 按需读取。保护输入绑定仍需独立工程依据。整个 LN 的类型不可解析时，属性目录没有可展开的定义，原因在原有类型引用检查中查阅。

## 验证

以 [T8.0 合成样本](../../tests/fixtures/scl/Task8Voltage.scd) 和测试中构造的变体为基础，覆盖以下场景。

- A 相幅值和相位、完整属性路径、MMS Item、实例描述、测量量与定值筛选、显式和推导 LD、ServerAt 与 IED/AP/Server 范围。
- 未入报告的有效映射、缺相位、缺失/歧义类型、同路径不同 FC、重复 FCDA、共享数据集、不同粒度的报告成员覆盖。
- 数组待选、有效下标/原始 `ix`、越界、inline selector、模板跨对象复用和原文标签。原文定位测试覆盖 UTF-8、带 BOM 的 UTF-8、UTF-16 LE/BE。
