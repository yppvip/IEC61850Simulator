# Task7 · T7.3 高级数据集层级与概览

2026-11-21。**T7.3 功能回归和本机只读验收通过。**

## 交付

- 高级「数据集」默认采用两级树表，也可切换平面列表。父项可按声明顺序或完整所属路径排序。分页、父项筛选及身份定位在后台执行。成员按原始 FCDA 顺序加载，每批最多 200 行，保留重复声明、解析状态和原文身份。
- 展开箭头及键盘操作独立于业务选择。加载行只执行取页。表格支持可见行换行测高、完整值复制和独立原文入口。切换层级和平面模式时保留成员身份，返回后按原始节点恢复选择、页和滚动锚点。
- 成员专页显示所属数据集路径和声明数，可返回数据集页。离开数据集或 FCDA 时清除成员范围。Tab 可见性仍按应用文本筛选前的范围内容决定。
- 概览显示工程统计、当前浏览范围、对象与所属路径、描述、分类入口及关系证据。数据集成员解析计数和使用方在后台查询。使用方列表分别标明报告、GSE、SV 与完整所属位置。关系跳转与帮助收尾属于 T7.4。

## 实现与边界

`SclDataSetView` 的模型只读取已交付的分页，按快照、请求代次、父数据集及展开状态接收结果。成员页可顺序追加，优先回收已收起的分支。树表和使用方界面共用 2,000 条缓存预算。点击展开时替换旧待处理请求，尚未交付的分支保留可继续加载的入口。历史保存有限展开集合，使用 NodeId 恢复父页及成员页。高级数据集筛选作用于父项，成员专页按指定数据集筛选。

成员专页与高级概览复用原 ADS 工作区。内部布局版本仍为 2。短窗初次验证发现默认上下分隔只留下表头，已为上下排列的数据集及成员页保留可读行空间。详情收起、浮动停靠和横向排列保留各自行为。完整值与展示预览通过独立角色取得，使用同一已加载快照。
