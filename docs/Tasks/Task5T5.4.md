# T5.4 · GOOSE/SV 发布成员查阅

GOOSE 和 SV 的发送配置页在发布流列表下方显示流概要及可调整高度的查阅区。使用「成员映射」「成员详情」和「网络端点」切换。外部输入继续使用原接收声明视图。

- 每页最多 200 条 FCDA，保留数据集中的原始序号。复用收发关系的成员描述投影。发布页按 FCDA 展示一次，分别计数明确映射与候选，并提供有证据的接收声明入口。
- 成员表保留完整字段。成员详情分列说明对象和属性的来源，并提供 FCDA、描述来源和接收声明原文。MMS Domain、Item 和数组索引保留推导或未知状态。
- 网络端点按 SubNetwork 和 AP 分行，APPID、MAC、VLAN-ID 和优先级独立展示，APPID 保留前导零。端点表 Enter 打开选中端点的原文。SV 概要显示原始 smpRate、smpMod、nofASDU 和 SmvOpts，换算依据未知时保持未知。
- 后台成员加载核验快照和请求身份。切换流、隐藏或切换范围会取消旧请求。历史按发布流与 FCDA 原始节点恢复成员页。

独立 Debug 构建目录为 `build/task5-t54`。
