# Task8 · T8.2 信号入口与证据

2026-11-21。T8.2 已通过。将 T8.1 的离线查询接入现有 SCL 工作台，复用任务导航、统一历史和 ADS 详情 Dock。复制引用的两级菜单按 [Task8](Task8.md) 在 T8.3 交付。

## 查阅路径

1. 在任务视图选定 IED，进入「MMS 查阅 → 信号地址 → 查找属性」。MMS 页的路线选择也提供「查找 MMS 属性」。输入 `A 相电压`、完整属性路径、MMS Item 或文件描述。可从「更多 → 按功能约束筛选」选择 `MX` 或 `SP` 等常见 FC。
2. 结果显示属性路径、IED/AP/Server/LD/LN、FC、匹配依据和直接映射状态。选择相位或幅值条目，在「MMS 字段与依据」核对 Domain、Item、DO/SDO、DA/BDA、FC 来源和在线状态。存在可定位的 `Val` 时，按原文记录显示文件值及适用的定值组。
3. 点击「查看报告使用」，按精确属性、上级属性或 DO 级覆盖查阅相关报告定义、数据集和原始 FCDA。可进入该报告的成员页，定位同一条成员声明。上一级和统一历史可恢复原查找结果的 IED、筛选、选择和滚动位置。
4. 在高级视图的对象表、数据集成员树、成员专页或 FCDA 引用行，按右键选择「在 MMS 中查阅属性」。实例和已解析 FCDA 按原路径及作用域定位。可用的数组下标与 alternate access 组件保留。共享模板显示当前范围内的实例候选。遇到未解析成员或缺少可定位属性时，可以由空态打开来源原文。

报告使用取自文件中的已解析链路，在线状态保持「未验证」。未找到报告使用、模型缺少属性、超出范围和查询受限各有提示。原文页到报告页的切换作为一次历史事务，避免详情页的同步信号覆盖来源记录。入口使用现有工作区和详情 Dock，持久化布局版本为 2。

## 验证

使用 `Task8Voltage.scd` 和测试中构造的变体。隔离 QSettings。Windows Debug 构建和运行库部署在 `build/task8-t82`，使用 Qt 6.11.1 / GCC 16.2.0。

- 原生 Qt 的 `1280 × 800` 和 `620 × 560` 窗口均通过属性检索、文件值、原文、报告使用、返回、详情收起及高级对象和 FCDA 跳转。普通窗额外走查了从未解析 FCDA 引用行进入来源原文。验证用例检查目标行、字段和原文位置与可见区域的交集。日志为 `build/task8-t82/T82Native1280.txt`、`build/task8-t82/T82Native620.txt`。
- 清洁 PATH 下 CTest 15/15 通过，耗时 42.47 秒，包含独立的 `SclMmsAttributeWorkflow` 和既有工作台测试。定向查询专项覆盖数组 FCDA、实例下标、共享模板候选、范围外与未解析声明。日志为 `build/task8-t82/T82CTest.txt`。
- 用 T8.1 构建写入隔离的 ADS 布局，再用 T8.2 启动，原导航与表格的同组布局和收起的详情 Dock 通过校验。日志为 `build/task8-t82/T82Layout.txt`。
