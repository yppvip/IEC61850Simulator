# T5.5 · 只读关系图投影

收发关系页以当前发布流、接收 IED 和选中 FCDA/ExtRef 为根，后台构建有类型的局部有向图。默认展示当前映射。点击「展开更多」可查看同一 FCDA 在当前关系中的其他接收声明以及描述依据。布局按发送 IED、发布流、成员、接收声明和接收 IED 分层。共享模板只出现在描述依据中。

节点和边保留快照内原文证据。成员以 FCDA 节点标识，映射同时带 ExtRef 身份，重复声明各自独立。图内同页映射可以定位到成员表，双击沿用原文导航。明确绑定、成员候选、包含候选和归属/依据分别编码。投影以现有关系证据为边界，不沿 IED 聚合推断内部信号因果。

投影请求独立取消，切换成员、分页、范围、快照或隐藏图页时清除图。节点上限 80、边上限 160，图显示隐藏映射计数或达到上限提示。图场景提供平移、缩放与原文查阅。

绘图继续使用现有 Qt Graphics View。此阶段为可选库试验，现有后端可表达本轮有界分层图和原文导航，因此未拉取 QtNodes，也没有 QtNodes 的同机比较结果。依赖和部署沿用现有 Qt 组件。

## 验证

独立 Debug 构建及运行时部署成功，CTest 9/9。合成测试覆盖重复 FCDA 的身份、候选与明确绑定分离、取消，以及 100 条映射触发节点上限和隐藏计数。Windows 原生清洁 PATH 下验证展开、关闭图页清理、重新打开及真实工程关系回归。真实样本本地索引 9 项通过，原文件 SHA-256 与 T5.0 相同。截图保留在忽略的构建目录。
