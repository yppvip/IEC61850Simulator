## 实施

`SclMmsPresentation` 在后台给信号对象、属性地址、报告成员投影 DO/SDO 与 DA/BDA 边界、CDC、基本类型、原始 doName/daName、成员序号和可信标签起始行。报告及其他记录保留原八字段契约。列表只读取当前交付页及已有类型/解析轨迹，不逐属性进行数据集扫描。

所选记录的字段详情复用 `SclObjectEvidence`，分别展示文件声明、引用解析、类型展开与规则组合；多输入来源保留各自字段及行号。MMS Domain、Item 和对象引用的完整值沿用既有投影，数组 alternate access 组件不拼进 Item。

`SclMmsEvidence` 在现有详情 Dock 中提供来源摘要与四组入口：

1. **数据集声明**：保留每次 FCDA 出现及对应 DataSet 标签。属性摘要由独立后台会话查询，保留精确属性、上级属性和 DO 覆盖；无引用与不确定/受限分开。来自报告或成员时先查当前来源数据集，并提供当前 IED/AP/Server 的全部数据集引用入口。
2. **实例配置**：精确实例单列。缺失叶 DAI 时显示停止段、回退原因和最深已证实祖先的标签起始行；不把模板节点当实例，不选择歧义候选。
3. **类型定义**：逐段定位实际类型声明和唯一解析的定义，和实例入口分开。
4. **查看地址组成**：复用 Task9 图和证据树；根值与既有完整复制值相同。

属性的数据集关系页复用中央任务表和统一历史，按 200 行分页，保留 DataSet 完整路径、原始序号、原始 doName/daName、覆盖类型、成员层级、FC、两类行号及报告/GOOSE/SV 静态使用方。重复 FCDA 和无使用方数据集不丢失；使用方资源限制、扫描完整性和未确定声明分别保留。该页面不表示在线收发。

普通窗展开摘要和入口；短窗将来源信息及三类原文/组成入口收进「对象来源 / 数据集证据与原文」菜单，和字段原文按钮共用一行。没有增加 Dock、持久化版本或页面最小尺寸，内部 ADS 仍为版本 2。原文和复制仍是显式独立动作。

新增会话按文档对象、请求身份和完整记录键核验结果。选择、范围、筛选、隐藏和关闭撤销旧摘要/动作，切文档同时更新该会话上下文。菜单动作不根据旧显示行号重新找对象。
