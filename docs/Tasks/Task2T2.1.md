# Task2 T2.1 · 导航与历史验收

2026-11-06 · T2.1 门槛通过。

- 左树选报告、数据集、FCDA、对象、通信或模板时，中央按实际表行切换并定位。IED、LD、LN/LN0 和没有对应表行的节点进入节点概览。概览显示作用域路径、直接子节点数及各分类的后代数，可定位分类首项。表格选行保留页签，反向展开并定位左树。
- 选择 FCDA 时先切换所属数据集的成员范围。全局搜索和引用激活按目标类型跳转，保留详情页阅读偏好。问题激活保持问题上下文并打开诊断行，同一节点上的不同诊断按各自的原始问题序号识别。
- 被筛选遮住的目标仍显示在树和详情，中央清除旧行高亮并提供清除筛选入口。跨表或跨成员范围时，现有后台筛选在新范围重新执行。分类行和筛选行使用有序索引查找。
- 前进与后退按当前快照的节点、诊断序号、成员范围和页签恢复，重新查找可见表行。回到搜索结果页时保留查询结果，清除旧行高亮。文档替换清除历史与旧查询状态。

## 验证

Windows / MSYS2 UCRT64，Debug 构建通过，`ctest --preset windows-debug` 7/7。工作台回归覆盖报告表到树、树到报告、引用到数据集、节点概览、树到 FCDA 成员、问题原文行、搜索路由、筛选遮挡及清除、前进后退和文档替换。

用指定真实 SCD 运行 `SclLocalAcceptance`，通过报告定位、引用、问题和原始 `rptID` 搜索。文件 SHA-256 前后一致。单次加载 8,936 ms；报告表跟随开启后，40 次离屏画面更新 P95 为 24.67 ms，低于 100 ms 预算。T2.0 的 15.70 ms 来自中央仍停在概览的工作台。两次计时均含窗口抓取。十轮加载、释放和峰值内存对照留到 T2.4。复现命令见 [T2.0](Task2T2.0.md)，本轮本地日志位于 `build/windows-debug/T2.1LocalAcceptance.txt`。
