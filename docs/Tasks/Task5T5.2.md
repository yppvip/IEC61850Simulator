# T5.2 · 信号表与收发成员页试点

2026-11-13。对应 [Task5](Task5.md)。独立 Debug 构建目录为 `build/task5-t52`，沿用 [T5.0](Task5T5.0.md) 的工具链和样本口径。

- 本机信号表与收发关系成员映射使用同一个单元格交互控制器。双击与 Ctrl+C 复制当前字段，右键提供复制单元格、复制行和完整值。Ctrl+Shift+C 按当前可见列顺序复制整行。Enter 调用现有原文动作；图节点和其他业务表继续沿用现有入口。
- 完整值角色从当前模型的原始实体取得信号描述、完整派生路径或成员字段。长值从已加载快照或后台交付的 200 行成员页读取。菜单用持久模型索引，模型重置后过期索引失效。空单元格保留原剪贴板，复制反馈只显示长度。
- 普通字段按词边界换行，长连续引用可在字符边界折行。保留字段原始换行；绘制和测高共享 QTextLayout。超过 4,096 字符的异常值显示长度与完整值入口。
- 测高缓存限制在视口和少量预取行。调整宽度、字体、样式和 DPI 会失效；模型换范围时重置。测高分批，并在同一模型内维持顶部行与行内像素偏移。信号默认描述索引对无 DOI 的 LN 复用模板来源。

## 验证与推广门槛

- Debug 构建和运行时部署成功，CTest 9/9。离屏 100%、150%、200% 均通过同一套复制与测高用例。覆盖 Unicode、换行、前导零、空值、超过 6,000 字符的字段、隐藏列、Enter 及调整列宽后的顶部行和像素偏移。1 千、5 万、50 万行的模型跳转均访问不足 100 个不同的显示行。
- Windows 原生、清洁 PATH、100% 缩放下，真实样本的信号与收发流程通过。成员 intAddr 双击复制且未发出原文动作。原样本指纹一致。工程界面回归继续校验 SV 14、GOOSE 5、PL 发布 19 条及描述原文。
- 同机单次 37,571 行信号结果：Ready 3,103 ms，详情 P95 63 ms，程序驱动滚动 P95 6.24 ms、最大 6.97 ms，峰值工作集 200,437,760 B。T5.0 对应 1,947 ms、63 ms、5.06 ms、197,095,424 B。加载增量约 59%，仍高于拟定的 15%，峰值增量约 1.7%。这些值不是多轮加载中位数或真实滚轮端到端计时。
- 试点可验证，推广门槛尚未通过。跨实体显示器动态 DPI、原生右键逐项操作及真实输入到绘制的复制时延仍待验证。当前滚动锚点覆盖同一模型内的重排，跨快照或筛选重置按现有导航逻辑恢复。
