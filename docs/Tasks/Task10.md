## 1. 需求判断与产品决策

需求清晰，足以制定方案，不需要额外信息才能开始 T10.0。主要目标是：在任务视图中，让初学者看懂“这是什么对象、为什么出现在这里、地址如何得到、数据集是否包含它、原文依据在哪里”。两个文件作为同一套需求的互补例子，按统一的来源模型实现和验收，不做文件名或厂商特判。

有三处需要统一含义，统一后没有实质矛盾。

1. **地址可推导与数据集包含是两个问题。** 属性可以通过当前 LN 实例引用的类型结构解析出来，即使没有 FCDA 逐项声明它。不能把“未逐项声明”统一写成“不在数据集中”：还可能由同 FC 的上级 DO/SDO 或结构属性成员覆盖。确实没有精确声明或有效覆盖时，才显示“当前范围未发现数据集引用”。
2. **实例配置缺省不等于模型不存在。** `DOI/SDI/DAI` 记录实例配置；类型定义也参与确定对象结构。没有对应 DAI，不能据此删掉已经唯一解析的类型属性；同样不能因为一个对象被称为“电压”或 CDC 看起来相近，就补造模板中没有的 `ang.f`、`cVal` 等路径。
3. **“合法”必须带判断边界。** 建议纳入“对象引用 / MMS Item 离线校核与定位”，回答当前文件模型与已支持映射规则是否支持这条引用。结果分开显示格式、模型解析、映射、数据集证据及限制。离线通过不表示设备存在该在线变量、允许访问或报告已经发送。

默认采用下列产品范围。

| 需求 | 决策 |
| --- | --- |
| 任务视图对象来源与用途不清楚 | 本任务主线；在列表和统一详情直接呈现，不要求先打开关系图 |
| 数据集、实例配置、类型定义三类原文 | 提供明确分开的入口；位置缺省时说明真实回退位置与原因 |
| `doName` / `daName`、对象级 / 属性级成员 | 显示原始声明边界，和展开得到的叶属性分开 |
| 高级视图缺少 CDC | 同步补充 CDC、类型和原始字段，复用同一证据投影 |
| 未入数据集但类型存在的属性 | 在信号地址中保留，并标注覆盖状态；不添加虚构 FCDA |
| 粘贴对象引用或 Item 后校核和跳转 | 适合纳入，排在共用证据与导航完成之后，见 T10.4 |
| 在线读取、订阅、自动修正工程、完整标准合规认证 | 保留现有独立交付边界；本任务只读离线 |

可选补充信息仅影响验收重点：最常用的 IED、是否有厂商点表、偏好的默认列。不要求用户先掌握 SCL 或补充这些信息。默认以本文件明确的两个样本对象和合成场景验收。

### 2.3 一个 Item 应如何讲清楚

以 ICD 的 `MMXU1$MX$PhV$phsA$cVal$mag$f` 为例，详情应先显示：

> 地址来源：LN 实例绑定的类型展开，并按 MMS 规则组合。数据集关系：`dsRelayAin` 的 `PhV.phsA / MX` 对象成员覆盖本属性；FCDA 未逐项声明 `cVal.mag.f`。在线访问：未验证。

| 片段或结论 | 如何取得 | 当前样本原文 |
| --- | --- | --- |
| `MMXU1` | LN 的空 `prefix`、`lnClass=MMXU` 和 `inst=1` 组合 | LN 第 5675 行；其 `lnType` 指向 LNodeType 第 6821 行 |
| `PhV` | LNodeType 的 DO 声明；引用 `CN_WYE_ALL` | 第 6826 行；DOType 第 7376 行，CDC 为 `WYE` |
| `phsA` | 上述 DOType 的 SDO 声明；引用 `CN_CMV` | 第 7377 行；DOType 第 7358 行，CDC 为 `CMV` |
| `cVal` 与 `MX` | `CN_CMV` 中 `DA cVal`，结构类型为 `CN_Vector`，有效 FC 为 `MX` | 第 7359 行 |
| `mag` | `CN_Vector` 的 BDA，继续引用 `CN_AnalogueValue` | 第 7652、7653 行 |
| `f` | `CN_AnalogueValue` 的 BDA，`bType=FLOAT32`；继承上层 DA 的 FC | 第 7608、7609 行 |
| `$` 及 FC 插入位置 | MMS 映射规则，非某个 XML 属性的原始文本 | 显示规则标识、版本及适用条件，不伪造“规则所在原文行” |
| 数据集覆盖 | FCDA 原声明 `doName=PhV.phsA`，`daName` 未声明，`fc=MX` | DataSet 第 1430 行、FCDA 第 1435 行 |
| 实例配置 | `DOI/SDI/DAI` 中对应的实际实例位置 | `phsA` 第 5700 行、`cVal` 第 5701 行、`mag` 第 5702 行、`DAI f` 第 5703 行 |

`Domain=TEMPLATEPROT` 也要独立解释：本例由 IED 第 42 行 `name=TEMPLATE` 与 LDevice 第 1119 行 `inst=PROT` 按现有命名规则组合；不能解释为一个名为 `TEMPLATEPROT` 的 XML 元素。显式 `ldName` 的情形另行标明。

同样的叶地址，在 SCD 第 2789 行可获得“属性级精确声明”证据；在 ICD 第 1435 行获得“对象级覆盖”证据。**相同字符串可以有不同形成过程和数据集证据，不能按最终文本去重后丢失来源。**

SCD 的 `PhV.res.cVal.ang.f` 则说明实例和类型也要分开：实例 `SDI res/cVal` 在第 7210、7211 行，只有 `mag/f` 实例配置（第 7212、7213 行），没有对应 `ang/f` 配置；类型却经 `PhV → res`（第 216114、221029 行）、`CN_CMV.cVal`（第 220864 行）、`CN_Vector.ang`（第 221963 行）到 `f`（第 221940 行）。应显示“类型属性可解析；无对应叶 DAI；当前已核对数据集范围未引用”，保留地址 `MMXU1$MX$PhV$res$cVal$ang$f`，不暗示有文件相角值或实际在线值。

## 3. 统一的对象与证据语义

### 3.1 分开回答五个问题

| 问题 | 可显示的结论 | 判定要求 |
| --- | --- | --- |
| 当前是什么层级？ | LN、DO/SDO、结构 DA/BDA、基本叶属性、数组模板/元素 | 跟随实际类型链；FCDA 行另保留声明层级 |
| 当前值从哪里来？ | 文件直接声明、引用解析、类型展开、规则组合 | 可多项并存；如原始 `daName` 是声明，完整 Item 是组合结果 |
| 实例有配置吗？ | 精确实例节点、仅到祖先、未声明、歧义/受限 | 不把未声明 DAI 当成不存在的属性；不把模板节点冒充实例节点 |
| 哪些数据集包含或覆盖它？ | 精确声明、上级属性覆盖、DO/SDO 级覆盖、无匹配、未确定 | 以同实例、同 FC、类型路径和数组边界核验；保留多个数据集和重复 FCDA |
| 可以如何使用？ | 文件模型可映射地址；报告/GOOSE/SV 的静态使用方证据 | 报告、GOOSE、SV 分列；设备在线访问、实际订阅均单列未验证 |

状态不能只做一个“已生成 / 未生成”标签。例如“类型展开 + 无叶 DAI + DO 级覆盖 + 离线映射通过”可以同时成立。数据集关系是一对多，不是对象的唯一父节点；默认列名用“数据集引用/覆盖”，不笼统使用“所属数据集”。物理归属仍为 IED/AP/Server/LD/LN。

### 3.2 数据集成员分型

| FCDA 原声明 | 成员类型 | 展开到叶属性后的展示 |
| --- | --- | --- |
| 有 `doName`，`daName` 未声明或显式为空 | 对象级成员（FCD）；保留未声明/空值差别 | 原 FCDA 仍是一条成员；可查看同 FC 结构中的已证实属性，标“DO/SDO 级覆盖” |
| `daName` 指向结构 DA 或结构 BDA | 结构属性成员 | 原始属性名保留；后代叶属性标“上级属性覆盖” |
| `daName` 指向基本叶属性 | 叶属性成员（FCDA） | 同 FC、同数组选择且唯一解析才标“精确声明” |
| 路径缺失、FC 冲突、候选不唯一 | 声明存在但解析失败/歧义 | 展示原始字段、停止段与候选；不将字符串前缀相似当成覆盖 |
| 数组未选元素、选择不完整或超界 | 数组成员/解释受限 | 独立展示数组维度与选择；不生成假标量 Item，不将一个元素覆盖所有元素 |

“FCDA”既是 XML 标签名，也常被用于数据属性术语。界面保留“FCDA 声明”这一原文名称，另列“成员层级”，避免让初学者以为所有 `<FCDA>` 都直接指向叶属性。

覆盖依据复用现有解析轨迹，核对实际 DO/SDO 与 DA/BDA 路径。不能按 `PhV` 的字符串前缀匹配 `PhV2`，也不能跨 LN、Server、FC 或数组元素传播资格。未支持或未知版本语境保留限制。

### 3.3 数据集覆盖状态与查询完整性

每个关系保留 DataSet 身份、FCDA NodeId、原始成员序号、原始 `doName/daName/fc/ix`、解析目标、匹配方式和原文。一个属性可同时被一个数据集精确声明、被另一个数据集对象级覆盖，两种证据都应可查。

负结论必须带范围与覆盖完整性：

- 从报告成员进入时，首先回答“当前报告所用数据集”的关系，同时可切“该属性全部数据集引用”。
- 从信号地址进入时，默认查当前 IED/AP/Server 语境内该信号的关系；可显式查整个工程的合法成员引用。原 FCDA 的所属范围与目标信号范围分别保存。
- 必须包含未被控制块使用的数据集，以及 GOOSE/SV 使用的数据集。当前仅报告反查没有结果，不能据此显示“没有数据集”。
- 已有确定命中可显示；受预算、解析失败或候选歧义影响，无法排除其他关系时同时标“尚有未确定关系”。仅当相关范围检索完整且不存在可能影响结论的未解析声明时，才显示“当前范围未发现数据集引用”。
- “未发现数据集引用”不是模型错误，不自动加入错误计数；“FCDA 声明指向不存在路径”才属于文件内部一致性问题。

### 3.4 CDC 与路径名称

列表及详情应区分 **DO 路径、属性路径和完整路径**。在 FCDA 行显示原始 `doName`、原始 `daName`，在叶属性行显示经模板确认的 DO/SDO 路径与 DA/BDA 路径；没有对应 FCDA 时，不把派生路径标成“原始 daName”。`$` 或 `.` 只是表示形式，不能单靠分隔符判断 DO/DA 分界。

CDC 绑定 DO/SDO 对应的 DOType，不绑定每个 BDA。`PhV` 显示 `WYE`，进入 `PhV.phsA` 显示当前对象 `CMV`，详情可显示 `WYE → CMV`。叶 `f` 显示“所属对象 CDC=CMV；基本类型 FLOAT32”，不声称 `f` 自身有 CDC。`Vol` 显示 `MV`。缺失/歧义类型显示相应状态，不取第一个候选。

CDC 可帮助解释业务结构和检查明显冲突，但**不能成为自动补齐可选属性的模板**。路径存在性以当前实例所绑定的、唯一解析的实际类型链为依据；标准 CDC 必选/可选项的完整符合性检查仍需独立规则与版本依据。

“信号地址”默认保留全部可解析模型属性，并可切“有数据集证据”“未发现引用”“尚未确定”；“报告成员”始终展示原声明，不混入类型额外展开的成员。“不在当前数据集”与“整个工程未发现引用”明确区别，避免切换页面后改变含义。

### 4.2 三类原文动作

1. **数据集声明。** 一条关系时跳到其 FCDA，显示所属 DataSet 名称和两个行号，可再定位 DataSet 标签；多条时列出 DataSet、原始序号、匹配类型、行号让用户选择。无关系时按钮显示“无已确认数据集声明”，并解释原因。用户要求的“最近一层”在此回退到同一业务来源中已证实的 DataSet、报告或 LN，不跳到别的数据集或别的属性。直接从目录进入且无关联时，没有可用的 DataSet 祖先，明确显示“无数据集来源，可看 LN/类型”，由用户显式选择。
2. **实例配置。** 优先到同 LN 下精确匹配的 DOI/SDI/DAI。没有叶节点时，沿已匹配的实例链回退到最深真实祖先，再到 DOI、LN；显示如“未声明 ang/f，定位到 SDI cVal 第 7211 行”。数组按声明和 `ix`、定值组等身份核验；分支歧义时选择候选或说明受限，不取首项。
3. **类型定义。** 定位 DO/SDO、DA/BDA 或所引用类型定义；每段均可查看。与实例入口并列，不能用 BDA 原文偷偷替代 DAI。仅有开始标签锚点时标“标签起始行”；无可信位置则说明不可定位，不能推算属性字节位置。

字段和依据表每个来源显示“来源类别 · 元素/属性 · 行号 · 定位精度”。多输入组合不能只给一个叶节点行号；规则说明没有 XML 行号，应列规则标识及其输入证据。保持显式原文动作，普通选行、复制、展开图不自动切换原文。

### 4.3 高级视图的一致性

高级对象和 FCDA 树表复用同一对象身份与来源投影：补充当前 CDC、DOType、成员层级、原始 `doName/daName` 与精确/覆盖说明。模板页保留模板身份；未绑定 LN 时只能显示模板结构，不能生成虚构实例地址。模板被多个实例复用时保留 IED 范围和候选。

任务/高级切换、原文、返回来源和校核跳转复用统一历史。选择恢复使用同快照记录键、字段键、原 FCDA 序号、父报告/数据集上下文及滚动锚点，不使用旧显示行号。改变范围或筛选前说明目标所在范围，用户显式跳转后临时定位目标并允许后退完整恢复；不得悄悄选择首行。

### 4.4 初学者文案与可读性

首次查阅在详情提供可折叠的短说明：“DO 是对象，DA 是对象的属性；数据集可以引用整个对象的某个 FC 部分，也可以引用具体属性；Item 是按规则得到的 MMS 名称。”业务释义有来源，不能仅因名称推断真实保护输入。

完整换行、可见行按需测高、异常长值入口和双击完整复制沿用 Task5。状态带文字，不仅用颜色；键盘可选择多来源、查看原文和返回。短窄窗不新增不可收起的大面板；详情收起后主表仍可读。沿用 Qt Widgets + ADS，内部布局版本 2；只有实际持久化 Dock 结构变化才另行版本化。

## 5. 对象引用 / MMS Item 离线校核与定位

### 5.1 为什么适合加入

它直接解决“粘贴一个引用后，不知道是否存在、由哪里得到、该去哪个页面看”的问题，复用本任务建立的证据和定位能力。建议作为 T10.4 有界功能纳入方案。名称使用“离线校核”，结果标题用“当前文件模型支持 / 不支持 / 尚不能确定”，不用一个不带限定的绿色“合法”。

### 5.2 输入与支持范围

- 从任务视图工具入口或表格引用菜单打开现有工作区内的校核页。一次校核一个引用，默认绑定当前不可变快照；重新输入或切文档会使旧结果失效。
- 输入类型显式选择“对象引用”或“MMS Domain + Item”。对象引用形如 `LDName/LNName.DO[.SDO…][.DA.BDA…]`，FC 可单独提供；MMS 输入将 Domain 与 Item 分栏，也可显式拆分 `Domain/Item`，保留粘贴原文及解析结果。
- 单独粘贴 `MMXU1$MX$…` 时 Domain 不是唯一确定的。允许用当前 IED/AP/Server 缩小范围，存在多个候选则列表选择，不取首项。对象引用不带 FC 时可核对路径；需要地址映射时列实际 FC 候选，不能默认 `MX`。
- 首期支持既有解析器已支持的普通 LN 对象、结构/叶属性及明确支持的数组选择。数组未选或多维/alternate access 尚未覆盖的输入保留“需补充选择 / 未支持”，不判不存在。
- RCB、数据集 MMS NamedVariableList、GOOSE/SV 控制引用等不属于本期普通信号 Item 语法。可识别类别并提示已有查阅入口；未实现相应规则不能直接判错。也不把 `rptID` 当 Item。

### 5.3 分层结果

| 层次 | 检查内容 | 结果边界 |
| --- | --- | --- |
| 输入格式 | 分隔符、空段、允许的标识形式、FC 与数组表示 | 只对支持的语法判格式错误；未知合法扩展归未支持 |
| 模型解析 | Domain/LD、Server、LN、DO/SDO、DA/BDA、FC、数组边界 | 沿实际类型链逐段解析；给出成功段、首个失败段、缺失/歧义类型与位置 |
| 映射一致性 | 有效 FC、命名来源、结构/标量形态、规则适用性；重新组合与输入核对 | 成功也标离线；DO/结构成立不等于具体叶变量或标量读取成立 |
| 数据集证据 | 精确声明、上级覆盖、未发现引用、未确定 | 独立结果；缺少数据集资格不否定模型引用或地址 |
| 在线与标准覆盖 | 当前工具实际执行了哪些规则 | 在线未验证；完整 XSD、完整 CDC/标准符合性不是本功能结论 |

支持范围内完整解析且映射一致的输入才显示“离线映射通过”。缺少 Domain、FC 或数组选择显示“需补充上下文”；类型歧义、资源受限、版本未解释显示“尚不能确定”。只有在目标范围和必要定义均可检查时，才能给出“该模型不存在此路径 / FC 不符 / 下标超界”，并展示依据。不得仅因为有界搜索列表中没找到就判非法。

`TEMPLATEPROT/MMXN1.Vol.ang.f` 的预期结果：成功解析到 `Vol`，在下一段 `ang` 停止；指向第 7386 行的当前 DOType，说明其实际声明不含 `ang`。可以提供“查看 Vol 的实际属性”，但不自动改成 `mag.f`。对应 `MMXN1$MX$Vol$mag$f` 则核对到当前模板；其数据集证据由第 1442 行的 `Vol/MX` 独立给出。

### 5.4 跳转契约

唯一确定的模型目标提供“到任务视图查阅”：叶属性进入“属性与地址”，对象进入“信号地址/对象详情”，结构停留当前层级并可继续展开。未入数据集属性同样可以跳转。

结果存在多个数据集或父报告时，先给“查看属性”这一中性入口，再由用户选择数据集/报告使用关系；不能为了导航伪造唯一父报告。歧义结果仅提供候选入口；失败结果提供“查看最后确认对象/原文”，不能把它标成对原输入的成功跳转。

导航目标由后台交付同快照范围、规范对象键、属性路径、FC、数组身份、声明身份和必要父上下文。执行时再次核验快照和结果请求代次。复用工作台定位查询和历史，定位目标真实可见行及字段；切换文档后旧结果不得导航到新文档同名对象。
