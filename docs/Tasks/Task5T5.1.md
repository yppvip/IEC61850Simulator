# T5.1 · 共享描述与结构化详情

2026-11-13。对应 [Task5](Task5.md) 的 T5.1。独立构建目录为 `build/task5-t51`，沿用 [T5.0](Task5T5.0.md) 的 MSYS2 UCRT64、GCC 16.2.0、Qt 6.11.1、CMake Debug 和 Ninja。

## 实现

- 信号目录在后台为每行记录默认描述的来源 NodeId。默认顺序为唯一且类型语义已确认的实例 dU、实例对象 desc、模板 DO/SDO desc。无描述时继续显示对象名称。模型取值直接读取来源节点的字段。
- 详情投影保留原值、来源类别、来源 NodeId、候选及状态。实例对象、模板对象、DOType、实例属性、模板属性和 FCDA 自身的 desc 分项展示。成员保留 LN、对象和属性路径、FC、数组索引及原始序号。来源节点使用当前分析快照的原文索引。
- 实例按 LN 实例身份和实际模板路径定位。重复声明、未指定的数组元素和定值组不能作为默认来源。FCDA 复用已解析的模板路径及数组选择证据。相同属性名出现在多个 FC 且实例没有 FC 区分时，保留歧义。各字段最多保留 16 个候选来源。
- 信号属性、GOOSE/SV 发布成员摘要和收发成员详情使用同一投影。收发页在「查看所选依据」中提供当前成员的描述来源。当前阶段沿用原有详情区、成员分页与跳转；表格交互、统一详情布局和 GOOSE/SV 完整成员表由后续阶段验收。

## 验证

合成用例覆盖未入数据集的信号、不同 AP 的实例复用、DO/DA 与成员声明分离、空值、重复成员身份、多 Val、定值组、未展开和明确选择的数组元素、同名不同 FC 的属性。真实工程采用本地同指纹副本，只读打开。通过 PL2201B 的 0131 发布配置选中 Break1PTRC1.Tr.phsA，在现有收发页分别打开对象实例 dU 和属性实例 desc。自动化核对原文高亮和返回路径，同时检查模板 DA 的 desc 显示为未声明。T4.6 的 14/5/19 断言继续运行。

最终 Debug 构建和运行时部署通过，CTest 9/9，本地索引测试 9 项通过。清洁 PATH 下 Windows 原生收发及信号流程通过，样本 SHA-256 仍与 T5.0 相同。

同机单次观测（37,571 个信号，1280×800，100% 缩放）：Ready 从 1,947 ms 增至 3,134 ms（+61%），峰值工作集从 197,095,424 B 增至 198,852,608 B（+0.9%），信号详情 P95 从 63 ms 到 64 ms，程序驱动滚动 P95 从 5.06 ms 到 4.82 ms。加载样本超过 Task5 拟定的 15% 增量目标。后续性能验收需多轮复测并压缩后台描述索引的重复路径解析。
