# Task2 T2.3 · 交互式引用拓扑

2026-11-06 · 实现及自动化验收通过。实体浏览器排版复核纳入 T2.4。

## 使用方式

选中报告、数据集、FCDA 或存在解析关系的对象，在「引用与使用方」页点击「打开引用拓扑」，也可右键相应树节点或表格行。应用在后台生成局部图，并请求系统浏览器打开本地只读页面。若系统无法打开，工作台提供重试和复制本地页面路径。

- 沿报告 → 数据集 → 按原文排序的 FCDA → 对象实例追查。点选节点或连线查看证据，再通过「以此为焦点」或双击节点切换局部图。
- 从 FCDA 的原始字段查看 IED 作用域、LD/LN、DO/SDO/DA/BDA、FC 见证和数组维度。缺失或歧义显示停止字段及已有候选。证据区包含同快照的有限 XML 片段、来源行和可复制的定位信息。
- 对象实例页反查引用同一实例、路径、FC 和数组访问的 FCDA。模板定义页单列引用同一模板的成员，可区分不同 LN 实例。成员所属数据集可继续从 FCDA 节点查看。
- 画布支持缩放、拖动、适配和关系高亮。关系列表可用键盘操作，按组展开和翻页。每组最多装载 24 条成员、使用方或候选，列表每页 8 条。页面最多装载 768 个节点和 160 个可聚焦视图，画布最多同时显示 80 个节点。达到上限时提示剩余关系或说明如何从主程序重新打开。

## 实现边界

领域层在现有解析分支保存 FCDA 的真实匹配步骤和停止字段。应用层使用这些证据、正反向索引及原文快照生成版本化局部数据。单文件 HTML 由 Qt 资源提供，通过 Base64 嵌入 JSON，并以文本节点显示工程字段。页面离线运行，使用 SVG `viewBox` 控制缩放和平移。 [SVG viewBox](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/viewBox)

临时页面包含当前局部证据和文件名，不包含源文件的完整内容或路径。切换文档时抑制旧任务的浏览器打开请求，已打开的页面保留其原快照。退出时清理会话目录，启动时尝试清理过期且未被运行实例锁定的页面。

## 验证

- Debug 构建通过，CTest 7/7。Qt 集成测试覆盖报告到对象及反查、同对象不同声明形式、跨实例模板复用、数组下标区分及越界、缺失、歧义、顺序和超量分组。测试通过 URL 处理器截获本地打开请求，核对 HTML、转义、切换快照后旧页内容及退出清理。
- `node tests/integration/SclTopologyPageTest.cjs` 通过。在模拟 DOM 中验证分组翻页、收起、边与节点选择、重新聚焦、缩放、平移和 80 节点上限。实际浏览器的渲染、键盘焦点及默认文件关联尚待人工复核。
- 指定真实 SCD 的 `SclLocalAcceptance` 通过，文件 SHA-256 前后一致。首个报告局部图生成耗时 36 ms，达到 768 节点和 160 视图的装载上限。单次加载 9,342 ms，40 次离屏导航 P95 为 32.92 ms。日志为 `build/windows-debug/T2.3LocalAcceptance.txt`。十轮性能对照留到 T2.4。
